# castor-localization

UWB indoor localization firmware, built on the vendored Qorvo/Decawave `DW3_QM33_SDK_1.1.1` driver
layer, targeting STM32 Nucleo boards paired with DWS3000 UWB shields.

See [`firmware/README.md`](firmware/README.md) for the per-board project layout, build/flash
instructions, and a step-by-step guide for adding another board (same MCU or a different one).
